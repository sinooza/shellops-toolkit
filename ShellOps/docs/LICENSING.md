# Licensing decision required

The project owner has selected the product name **ShellOps — Helpdesk Tools**, but has not yet selected a software license.

Do not add a license by assumption. Before describing the repository as open source or inviting reuse, choose a license and add its complete canonical text as `LICENSE` in the repository root. Without a license, default copyright law applies and public visibility alone does not grant permission to copy, modify, redistribute or use the code.

Common choices include MIT (simple permissive), Apache-2.0 (permissive with explicit patent terms), and GPL-3.0 (copyleft). The right choice depends on the owner's distribution and contribution goals. This note is informational, not legal advice.
