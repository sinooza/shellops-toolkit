# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in the ShellOps project a respectful experience for everyone, regardless of experience level, background, identity or viewpoint.

## Expected behavior

- Be respectful and constructive.
- Assume good intent while discussing technical disagreements.
- Accept feedback and focus on the code, not the person.
- Share technical context without condescension.

## Unacceptable behavior

Harassment, insults, discrimination, threats, doxxing, sustained disruption, and publishing another person's private information are not acceptable.

## Enforcement

Project maintainers may edit or remove contributions and may restrict participation for behavior that violates this code. Report concerns privately using the contact route described in `SUPPORT.md`. Do not report security vulnerabilities in public issues.
