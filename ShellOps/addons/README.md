# Optional add-ons

This directory contains integrations maintained separately from the ShellOps core. Add-ons are not loaded automatically by the desktop application. Review their source and documentation before use.

- [ServiceDesk Plus](servicedesk/README.md): standalone read-only API module.
- Horizon: no add-on is currently included. A future integration must be implemented and reviewed as a separate package; the core contains no Horizon code or UI.

Each add-on should document supported versions, permissions, network access, data handling, configuration, installation, removal and testing.
